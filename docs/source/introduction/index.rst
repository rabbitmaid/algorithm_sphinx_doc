Introduction to Algorithms
===========================

An algorithm is a finite set of instructions carried out in a specific order to perform a particular task in order to solve a problem. This can be a real life problem, mathematical problem or a computational problem. The algorithm is made up of different calculations and steps that lead to the overall solution of the problem.

Basic Requirements to start learning
-------------------------------------
 - Basic Understanding of how computers store memory.
 - Basic Arithmetic (Addition, Subtraction, Multiplication and Division)

Characteristics of Good Algorithms
------------------------------------
 - **Input:** An algorithm may have many or no inputs to be processed.
 - **Output:** An algorithm is written to solve a problem, therefore it must produce one or more solutions called outputs
 - **Unambiguous:** Each algorithm step should have one meaning and leave no room for doubt or multiple interpretations.
 - **Finiteness:** An algorithm must terminate after a limited number of steps.
 - **Efficiency:** An algorithm should produce a result for the problem it is trying to solve.
 - **Language Independent:** An algorithm can be implemented in any language with the same result as output.

How to develop an Algorithm
------------------------------------
 - Properly understand the problem statement so as to make an algorithm that solves the problem.
 - Study the outputs to be generated so that the inputs can be specified.
 - Design the process that will produce the desired result after taking the input.
 - Test the algorithm by using test data to see if the desired output is generated.
 - Carry out appropriate changes and repeat the process.

Advantages of Algorithms
----------------------------------
 - It provides a step-by-step solution to a given problem, which is easy to understand.
 - It has a definite procedure, which can be executed within a set period of time.
 - After developing an algorithm, you can convert it into any programming language of your choice.

Disadvantages of Algorithms
----------------------------------
 - As an algorithm grows, it becomes difficult to debug.
 - It is time-consuming and cumbersome, as an algorithm is developed first before converting it into a programming language.
 - Understanding complex logic through algorithms can be very difficult.
